# Locate your Momento Account ID

Your Momento Account ID uniquely identifies an account and its resources. You will need it when
asking Momento to register an AWS Marketplace agreement or activate a paid support plan.

An Account ID begins with `a-`. It is different from the editable Account Name, which is not unique
and cannot identify an account for a support or purchase request.

## Before you begin

Make sure you can sign in to the [Momento Console](https://console.gomomento.com/) and access the
account that the request concerns.

## Find the Account ID

1. Sign in to the [Momento Console](https://console.gomomento.com/).
2. If you belong to more than one account, select the account that the request concerns.
3. Open the account menu and copy the value that begins with `a-`.

Verify that you copied the Account ID, not the Account Name. Include the Account ID in any request
that requires Momento to identify that account or its resources.
